01

Performance no CRM dos Assessores (Squad Flow)

Contexto
A tela de autoatendimento de taxas fazia uma rota por cliente — um clássico N+1 — levando o carregamento a minutos.
O que construí
Reescrevi a tela em Next.js e .NET, transformando as rotas por cliente em rotas em lote, e implementei carregamento via streaming.
Resultado
-75% de requisições e tempo de carregamento caindo de minutos para segundos. Apliquei a mesma arquitetura na lista de clientes e assumi a migração de fluxos legados para Next.js, como o de cotação indicativa.
Next.js.NET
02

Programa Seeker

Contexto
O programa de indicação de clientes do Marketing dependia de geração manual de link, contrato e rastreio de conversão.
O que construí
Sistema em que a inscrição já gera automaticamente o link e o contrato, via integração entre HubSpot e ClickSign; ecossistema de dados (captura de leads, status de assinatura) arquitetado no Firestore.
Resultado
O time de dados passou a cruzar essas informações com a base de clientes para mapear conversões e viabilizar remuneração.
FirestoreHubSpot APIClickSign API
03

Zenith

Contexto
Construía landing pages rápidas e otimizadas para SEO, muitas vezes desenhadas e publicadas no mesmo dia para aproveitar o timing de oportunidades do mercado financeiro. O fluxo tradicional entre design e código tornava a criação de cada página lenta demais para essa velocidade.
O que construí
Uma biblioteca com cerca de 30 seções moduláveis, construída nativamente no editor drag-and-drop do HubSpot.
Resultado
Designers passaram a publicar páginas de forma totalmente autônoma, sem depender de engenharia.
ReactNext.jsHubSpot
04

Otto, agente de IA para o financeiro

Contexto
O time financeiro recebia faturas por e-mail e registrava cada uma manualmente no ERP NetSuite.
O que construí
Um agente de IA que lê as faturas diretamente da caixa de entrada do financeiro e as registra automaticamente no NetSuite.
Resultado
Redução do trabalho manual da equipe de finanças na rotina de lançamento de faturas.
IANetSuite
05

API de WhatsApp

Contexto

O que construí
API proprietária em NestJS: aquisição e configuração técnica do número, integração com a API oficial da Meta e o HubSpot.
Resultado
Entrega de um canal de comunicação totalmente novo para a equipe.
NestJSMeta API
