01

Advisor CRM Performance (Squad Flow)

Context
The rate self-service screen made one request per client — a classic N+1 — pushing load times into the minutes.
What I built
Rewrote the screen in Next.js and .NET, batching the per-client routes into a single request and adding streaming-based loading.
Result
-75% requests and load time dropping from minutes to seconds. Applied the same architecture to the client list and took on migrating legacy flows to Next.js, including the indicative-quote flow.
Next.js.NET
02

Programa Seeker

Context
Marketing's referral program relied on manually generating links, contracts, and tracking conversions.
What I built
A system where sign-up automatically generates the link and contract, through HubSpot and ClickSign integration; built the data ecosystem (lead capture, subscription status) on Firestore.
Result
The data team started cross-referencing this with the client base to map conversions and calculate payouts.
FirestoreHubSpot APIClickSign API
